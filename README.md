## 📚 Python Concepts Used

This project helps in understanding the following Python concepts:

### 1. Variables

Variables are used to store data in a program.

Example:

```python
name = "Saad"
age = 20
```

### 2. User Input

The `input()` function is used to take information from the user.

```python
name = input("Enter your name: ")
```

### 3. Conditional Statements

`if`, `elif`, and `else` are used to make decisions in the program.

```python
if choice == "1":
    print("Option 1 selected")
else:
    print("Invalid choice")
```

### 4. Loops

Loops are used to repeat a block of code.

```python
for i in range(5):
    print(i)
```

### 5. Collections

Python collections can be used to store and manage multiple values.

Examples:

* List
* Tuple
* Set
* Dictionary
